About This Project

This project serves a twofold purpose:

1. Primary Goal: Public Release of Nationwide CDI Datasets

Providing ready-to-use, standardized Concentrated Disadvantage Index (CDI) data for all U.S. census tracts (N = 84,208) and counties (N = 3,142) constructed from U.S. Census Bureau American Community Survey (ACS 5-year estimates) data. The datasets include raw component proportions, standardized z-scores, and multi-version principal component (PCA) index scores (V1: 4-item baseline, V2: 5-item +education, V3: 6-item +income) scaled across National, State, and County levels for use in academic and policy research on neighborhood inequality, criminological theory, and public safety.

2. Secondary Goal: Replication Materials for Paper Analysis

Providing complete replication code, merged datasets, and statistical models for the manuscript "Misappropriating Vulnerability: Assessing the Utility of the Social Vulnerability Index as a Predictor of Firearm Violence" (Vogel et al., under review). The paper critically evaluates the conceptual foundations and empirical performance of the CDC Social Vulnerability Index (SVI) relative to the conventional CDI in predicting community firearm homicides across 84 U.S. cities.

Unlike emergency-management indices such as the CDC SVI—which gauge general community capacity to absorb natural disaster shocks—the CDI specifically captures structural economic disadvantage, family structure, public assistance reliance, unemployment, education, and household income.

Variable Codebook

Key variables included in the primary tract-level and county-level release files ((created) cdi_tract_level_release.csv/.RDS and (created) cdi_county_level_release.csv/.RDS).

Variable Name Type Description & Construct
tract_fips / county_fips Numeric / String 11-digit Census Tract FIPS code or 5-digit County FIPS code uniquely identifying geography.
state_fips String 2-digit State FIPS code.
disad_national_v1 / v2 / v3 Numeric CDI (National Level): PCA score standardized across all U.S. tracts/counties (V1 = 4-item baseline, V2 = 5-item +education, V3 = 6-item +income).
disad_state_v1 / v2 / v3 Numeric CDI (State Level): PCA score standardized within each state.
disad_county_v1 / v2 / v3 Numeric CDI (County Level - Tract dataset): PCA score standardized within each county.
pr_female_hh Numeric Proportion of female-headed households with no spouse present (ACS B11001).
pr_pov Numeric Proportion of population living below 100% poverty threshold (ACS C17002).
pr_pubassi Numeric Proportion of households receiving public assistance income (ACS B19057).
pr_unemprate Numeric Civilian unemployment rate for population age 16+ (ACS B23001/B23025).
pr_hs_or_low Numeric Proportion of population age 25+ with high school education or lower (ACS B06009).
median_income Numeric Median household income in past 12 months (ACS B19013).
pr_std_* Numeric Standardized z-scores for each component item (income is reverse-coded).

Replication Code & CDI Scripts

This project provides code both for nationwide CDI dataset construction and for reproducing the original paper analysis. The complete replication package containing all scripts, raw data, and documentation can be downloaded directly or accessed on GitHub.

Download Full Replication Package (.ZIP) View GitHub Repository ↗

Replicating Full Paper Analysis: To reproduce all regression models, summary statistics, and figures in the original manuscript (Tables 1–3, Appendices 2–4, Figures 1–2), run Scripts 01 through 04 followed by the Stata do-file analysis_260509.do.

Replicating Nationwide CDI Dataset Creation: If your primary goal is to construct or replicate the nationwide Concentrated Disadvantage Index (CDI) datasets directly from raw ACS Census data, see:

  • Script 01 — Pulls ACS Census variables and builds tract component items.
  • Script 05 — Constructs the nationwide tract-level CDI release dataset (National, State, and County scaled V1, V2, V3).
  • Script 06 — Extracts county-level ACS Census variables directly (like Script 01) and constructs the nationwide county-level CDI release dataset (National and State scaled V1, V2, V3).
01

1_tract level concentrated disadvantage items_260510.R

Constructs CDI components from Census ACS 5-year estimates. Outputs (created) concentrated disadvantage items.RDS.

02

2_American Violence data cleaning_260508.R

Cleans and merges American Violence Project firearm homicide data with CDC SVI and CDI; computes PCA scores (National, State, City). Outputs (created) finaldata_260508.RDS/.csv.

03

3_Other Figures_260508.R

Generates paper correlation plots (sub-items & composite) and interactive Leaflet map in Figure/.

04

4_county level robustness check.R

Aggregates CDI & SVI to county level and performs PCA for robustness checks. Outputs (created) finaldata county level_260508.RDS/.csv.

05

5_tract level cdi for release.R

Generates nationwide tract-level release files with V1, V2, V3 scores scaled across County, State, and National levels. Outputs (created) cdi_tract_level_release.RDS/.csv.

06

6_county level cdi for release.R

Extracts county-level ACS indicators directly via tidycensus (like Script 1) and generates nationwide county-level release files with V1, V2, V3 scores scaled across State and National levels. Outputs (created) cdi_county_level_release.RDS/.csv.

07

analysis_260509.do (Stata)

Executes primary statistical modeling: OLS, Negative Binomial, Poisson, Standardized IRRs, Leverage diagnostics, V1–V3 comparisons, and County robustness.

R ≥ 4.0 Stata 16+ tidyverse sf psych corrplot leaflet
